# Flud Companion branding

The linked-rings mark is the primary Flud Companion visual identity for the 0.24 release line.

Use the canonical mark consistently for:

- Android app icon;
- Android Bridge brand header;
- Local Web Companion;
- Remote PWA;
- Android TV presentation;
- public repository/release artwork.

The project name is **Flud Companion**. It is an independent alexlab.media project and is not affiliated with, endorsed by, or sponsored by Delphi Softwares or the developers of Flud. “Flud” is used only to identify compatibility.

Do not include private pairing QR codes, relay tokens, hostnames or signing material in screenshots or promotional artwork.
