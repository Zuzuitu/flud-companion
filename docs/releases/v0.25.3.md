# Flud Companion 0.25.3

Android TV / NVIDIA Shield Auto-start reliability update.

## What's improved

- Improved Accessibility helper binding behavior after Android TV reboot.
- Clear reconnection guidance when Android shows Auto-start enabled but the helper is not connected.
- Safer magnet and `.torrent` sending: if Accessibility disconnects before handoff, Companion reports the failure instead of proceeding without a connected helper.
- Existing LAN/Remote features and guarded single-handoff behavior are preserved.

## Updating

Install the signed 0.25.3 APK over 0.25.2. Your existing pairing and settings are preserved; no uninstall is needed.
