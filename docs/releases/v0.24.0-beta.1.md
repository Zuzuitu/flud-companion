# Flud Companion 0.24.0 Beta 1

First public beta of the sanitized Flud Companion release source.

## What works

- Android / Android TV Bridge for Flud and Flud+ compatibility.
- Local LAN controller on port `8765`.
- One-scan Local QR pairing.
- User-owned Remote relay using Cloudflare Workers + R2.
- One-scan Remote QR pairing.
- Remote sending tested over mobile data.
- Optional guarded Auto-start through Android Accessibility.
- English, Romanian, French and German UI.
- Browser-local recent sends and support reminder; no project telemetry.

## Architecture

At home:

`Phone browser → LAN Bridge → Flud`

Remote:

`Phone PWA → your Cloudflare relay → outbound HTTPS polling → Android Bridge → Flud`

No inbound home-network port and no project-owned relay account are required.

## Hardware validation

The beta was smoke-tested on real Android TV hardware with successful APK installation, LAN pairing, Remote pairing, magnet handoff, Remote use over mobile data and guarded Accessibility Auto-start.

## Security and privacy

- Pairing tokens and QR codes must be kept private.
- The self-host relay stores a SHA-256 hash of the Remote token.
- Signing material and private development relay configuration are excluded from the public source repository.
- The public source tree is checked by an automated source-hygiene workflow.
