# Flud Companion 0.24.7

Stable maintenance release focused on Auto-start reliability.

## Fixed

- Fixed an Auto-start status bug where the Accessibility helper could be enabled in Android settings but still appear as OFF in Flud Companion.
- Improved automatic download start reliability on slower Flud startups, especially when roughly 8-10 or more torrents are active and the existing torrent list takes longer to become ready.
- Auto-start now waits for Flud's real torrent list to become visible before handing over a magnet, avoiding unnecessary fixed delays when Flud is already ready.
- Small stability improvements.

The project remains free, open source and independent from the Flud developers.
