# Flud Companion 0.25.0

This release adds direct `.torrent` file sending alongside magnet links.

## What's new

- Send `.torrent` files directly to Flud from the LAN or Remote PWA.
- Improved iPhone/iPad Files compatibility when choosing `.torrent` files.
- Optional Auto-start works with both magnet links and `.torrent` files.
- Minor file-picker and stability refinements.
