# Flud Companion 0.24.1

First stable release of Flud Companion.

## Highlights

- Saved pairing in the Remote PWA can now be hidden and shown again without removing the pairing.
- Small bug fixes and stability improvements.
- Signed Android APK for Android / Android TV, including NVIDIA Shield.
- LAN and user-owned self-hosted Remote modes remain supported.

The project remains free, open source and independent from the Flud developers.
