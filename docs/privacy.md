# Privacy

Flud Companion is designed to work without a project-owned account or analytics backend.

## LAN mode

LAN control stays between the browser and the Android Bridge on the local network. The LAN API token is generated by the Bridge and, after pairing, is stored only in the browser that scanned or entered it.

## Remote mode

Remote uses a Cloudflare Worker + R2 mailbox deployed into the user's own Cloudflare account. The Android Bridge connects to that relay using outbound HTTPS polling. The project does not require a shared alexlab.media relay.

The relay stores a SHA-256 hash of the Remote token rather than the token itself. The Device ID identifies a mailbox but is not intended to be the authentication secret.

## Browser-local data

The Web Companion may store locally:

- pairing credentials for that browser;
- recent magnet-send history;
- language preference;
- Auto-start preference;
- successful-send count used only for the optional support reminder.

The support counter is not telemetry and is not sent to alexlab.media. Different browser origins, such as LAN and Remote, maintain separate browser-local storage.

## What to keep private

Do not share live pairing QR codes, LAN tokens, Remote tokens, Cloudflare credentials or signing material.
