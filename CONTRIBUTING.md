# Contributing to Flud Companion

Thanks for helping improve Flud Companion.

## Before opening an issue

- Check the existing issues first.
- Use the Bug report form for reproducible problems.
- Use the Feature request form for ideas and improvements.
- For setup problems, check the Quick start and Troubleshooting guides before reporting a bug.

## Privacy and security

Never post live credentials or private pairing data in an issue, pull request, screenshot or log. This includes:

- LAN API tokens;
- Remote relay tokens;
- pairing QR codes;
- Cloudflare API tokens;
- passwords, keystores or private deployment credentials.

For security vulnerabilities, use GitHub's private security advisory flow instead of a public issue. See [SECURITY.md](SECURITY.md).

## Bug reports

A useful bug report includes:

- Flud Companion version;
- Android / Android TV device and OS version;
- whether the problem affects LAN, Remote or both;
- clear reproduction steps;
- expected and observed behavior;
- sanitized logs or screenshots when useful.

## Pull requests

Keep changes focused and avoid mixing unrelated refactors with a fix or feature. Update documentation when behavior or setup changes.

Before submitting, verify the affected flow on the relevant platform and make sure no secrets or private relay details are included in the diff.

## Project scope

Flud Companion is an independent companion project for Flud / Flud+. It is not affiliated with, endorsed by, or sponsored by Delphi Softwares or the developers of Flud.
